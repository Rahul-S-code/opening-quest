# Opening Quest

A voice-guided chess coach for kids. Grandpa Rook teaches seven openings one move at a time, explains why each move is good, and explains what a different move would miss.

- As White: Italian Game, Ruy Lopez, Queen's Gambit, London System, Scotch Game
- As Black: Sicilian Defense (Dragon), Caro-Kann Defense
- Each lesson: 6–7 opening missions, then 5 "plan" moves after the opening

Live site: https://rahul-s-code.github.io/opening-quest/

Everything is in `index.html` (no build step). Narration uses the browser's built-in speech voices; Microsoft Edge's "Natural" voices sound best.
